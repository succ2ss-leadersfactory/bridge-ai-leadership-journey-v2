# 라운드별 콘텐츠 밀도 균질성 QA

이 문서는 Bridge AI Leadership Journey v2.0의 각 라운드가 같은 수준의 교육적 밀도와 구조를 유지하는지 점검하기 위한 QA 문서입니다.

## 1. QA 목적

라운드별 콘텐츠는 단순히 분량이 비슷하다고 좋은 것이 아닙니다. 교육생이 각 라운드에서 같은 수준의 판단 경험을 하려면 다음 기능이 균형 있게 들어가야 합니다.

- 장면이 구체적으로 보인다.
- 후배의 행동과 말이 드러난다.
- 리더가 흔들릴 만한 압박이 있다.
- A/B 선택 모두 장점과 비용을 가진다.
- 선택 이후 후배 반응이 달라진다.
- 추가 상황이 처음 판단을 다시 보게 만든다.
- 2주 실행안과 5줄 대화문으로 자연스럽게 이어진다.
- 모바일 화면에서 읽기 편하다.

## 2. 밀도 기준

| 기준 | 설명 | 5점 기준 |
|---|---|---|
| 장면 밀도 | 시간, 장소, 업무 맥락, 현장 압박이 보이는가 | 읽으면 바로 장면이 그려진다 |
| 선택 비용 | A/B 어느 쪽도 완전한 정답이 아니며 각각 비용이 있는가 | 두 선택 모두 장점과 손실이 선명하다 |
| 후배 반응 차별성 | A/B 선택에 따라 후배가 다르게 받아들이는가 | 선택별 감정·해석·다음 행동이 다르다 |
| 추가 상황 압박 | 처음 판단을 다시 보게 만드는 새 변수나 압박이 있는가 | 유지·보완·전환을 고민하게 만든다 |
| 실행안 연결성 | 2주 실행안과 5줄 대화문으로 자연스럽게 이어지는가 | 최종 산출물이 라운드 딜레마를 해결한다 |
| 모바일 가독성 | 짧은 문단, 줄바꿈, 화면 호흡이 적절한가 | 스마트폰에서 읽기 부담이 낮다 |

## 4. 라운드별 최신 진단

### R1. 확인받는 윤동희 사원

**현재 상태**

- 후배의 꼼꼼함과 확인 의존이 분명합니다.
- A/B 선택 비용이 명확합니다.
- 2주 실행안과 5줄 대화문 연결성이 높습니다.

**판정**

```text
유지
```

### R2. 빠르게 한 황성빈 대리

**현재 상태**

- 대표 테스트 라운드로 가장 균형이 좋습니다.
- 빠른 실행이라는 강점과 기준 누락이라는 비용이 선명합니다.
- 선택별 후배 반응과 실행안 연결이 잘 맞습니다.

**판정**

```text
유지하되 파일럿 후 문구 반응만 미세 조정
```

### R3. 실수 후 위축된 전민재 사원

**보완 완료 내용**

- 첫 안내 문장, 대체 경로 안내, 책임 질문 발생 시 넘길 기준을 구체화했습니다.
- “끝까지 혼자 처리”가 아니라 “첫 안내 문장과 넘길 기준을 가진 작은 재진입”으로 목표를 낮췄습니다.
- 2회 동행 후 단독 첫 문장 시도라는 복귀 흐름을 추가했습니다.
- A/B 선택 결과에도 위로만으로는 부족한 지점, 기준 복기만으로는 앞서는 지점을 반영했습니다.

**판정**

```text
재진입 역할 구체화 완료
```

### R4. AI 초안을 쓴 고승민 대리

**보완 완료 내용**

- AI 초안의 위험을 “어색한 문장”이 아니라 “자연스럽지만 검증되지 않은 문장”으로 구체화했습니다.
- 공항 안내 문구에서 사람이 확인해야 할 기준을 출처, 확정 여부, 표현 수위로 정리했습니다.
- 보상 표현, 확정 안내, 유관 부서 확인 전 표현의 위험을 보강했습니다.
- A/B 선택 결과에도 책임 원칙만 남기는 경우와 검증 체크리스트를 남기는 경우의 차이를 반영했습니다.

**판정**

```text
AI 검증 현실성 보완 완료
```

### R5. 더 맡고 싶어 하는 윤동희 사원

**보완 완료 내용**

- 탑승동 안내 동선 조정, 운영부서, 안내데스크, 시설 담당자 등 유관 부서 맥락을 추가했습니다.
- 협업부서 답변 지연, 배포일 변경, 현장 안내 표현 확정의 리스크를 넣었습니다.
- A 선택은 신뢰를 주지만 안전선이 흐릿해지는 비용을 강화했습니다.
- B 선택은 속도는 조금 느리지만 더 크게 맡기기 위한 기준을 세우는 방향으로 정리했습니다.

**판정**

```text
위임 경계 밀도 보완 완료. 파일럿 후 현장 용어만 미세 조정
```

### BOSS. 보고 직전 수습과 육성

**보완 완료 내용**

- 본부장 보고 30분 전, 운영부서 추가 확인 메시지, 즉시 조치 표현 오류 등 압박을 구체화했습니다.
- 후배에게 남길 작은 역할을 오류 표현 표시, 원문 출처 확인, 수정 근거 한 줄 작성으로 명확히 했습니다.
- A 선택은 빠른 수습 대신 후배가 배제되는 비용을 강화했습니다.
- B 선택은 보고 리스크를 관리하면서 수습 안의 작은 역할을 남기는 구조로 정리했습니다.
- 보고 후 15분 리뷰를 통해 질책이 아니라 다음 AI 초안 검증 기준을 남기는 흐름을 추가했습니다.

**판정**

```text
최종 라운드 완결성 보완 완료
```

## 6. 남은 점검 항목

현재 콘텐츠 구조상 큰 밀도 불균형은 해소되었습니다. 남은 점검은 파일럿 후 실제 반응 기반으로 진행합니다.

| 점검 항목 | 확인 시점 |
|---|---|
| 한국공항공사 실제 용어와 절차 적합성 | 파일럿 전 또는 파일럿 직후 |
| 모바일에서 상황문 길이가 부담스럽지 않은지 | 파일럿 테스트 |
| 교육생이 A/B 선택 비용을 충분히 이해하는지 | 파일럿 토의 중 |
| AI 프롬프트 결과가 5개 실행안과 5줄 대화문으로 잘 나오는지 | 파일럿 테스트 |
| 강사용 대시보드 토의 질문과 라운드 내용이 잘 연결되는지 | 파일럿 운영 중 |

## 7. 수정 원칙

라운드 밀도를 다시 조정할 때는 다음 원칙을 지킵니다.

1. 상황문만 길게 늘리지 않습니다.
2. 선택 결과와 후배 반응도 함께 조정합니다.
3. 추가 상황은 처음 선택을 다시 보게 만드는 역할을 해야 합니다.
4. 실행안은 반드시 2주 안에 가능한 작은 행동이어야 합니다.
5. 5줄 대화문은 실제 과장이 입 밖으로 낼 수 있어야 합니다.
6. 모든 라운드를 같은 길이로 만들 필요는 없지만, 같은 수준의 판단 압박은 있어야 합니다.
