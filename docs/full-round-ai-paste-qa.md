# 전체 라운드 AI 붙여넣기 QA 체크리스트

이 문서는 R1~BOSS 전체 라운드에서 AI 답변 붙여넣기와 자동분리, fallback, 저장, 대시보드 표시가 정상 작동하는지 확인하기 위한 파일럿 전 QA 시나리오입니다.

## 1. 목적

최근 AI 답변에서 코칭 대화문 3번과 4번이 비어 있거나 `아직 참여하지 않았습니다`로 표시되는 문제가 확인되었습니다. 현재 파서 fallback이 보강되어 아래처럼 자동 보완됩니다.

| 비어 있는 항목 | fallback 대상 |
|---|---|
| 3. 이번 주에 같이 해볼 일 | 이번 주에 맡겨볼 작은 일 |
| 4. 김원중 과장이 봐줄 선 | 김원중 과장이 옆에서 도와줄 일 |
| 5. 입 밖으로 내면 안 좋은 말 | 말할 때 조심할 표현 |

이 문서는 해당 보완이 실제 라운드별 사용 흐름에서도 작동하는지 확인하기 위한 체크리스트입니다.

## 2. 테스트 전 준비

테스트 전 아래 항목을 확인합니다.

- [ ] 최신 Vercel 배포가 Ready 또는 success 상태다.
- [ ] `/?view=check`에서 시트/헤더 점검이 통과한다.
- [ ] Google Sheets의 `Participants`, `Responses` 시트가 존재한다.
- [ ] 테스트용 팀명과 닉네임을 정했다.
- [ ] 외부 AI에 복사·붙여넣기 할 수 있다.

## 3. 로컬 코드 점검 명령

로컬에서 확인할 경우 아래 순서로 실행합니다.

```bash
npm run typecheck
npm run audit:linebreaks
npm run smoke:parser
npm run build
```

각 명령의 의미는 다음과 같습니다.

| 명령 | 확인 내용 |
|---|---|
| `npm run typecheck` | TypeScript 타입 오류 확인 |
| `npm run audit:linebreaks` | 붙어 읽어야 하는 표현의 부자연스러운 줄바꿈 확인 |
| `npm run smoke:parser` | AI 답변 파서 fallback 동작 확인 |
| `npm run build` | Vite production build 확인 |

## 4. 공통 테스트 절차

각 라운드마다 아래 절차를 반복합니다.

1. 교육생 화면 `/` 접속
2. 테스트용 팀명과 닉네임 입력
3. 해당 세션과 라운드 선택
4. 상황 읽기
5. 후배 행동 읽기 입력
6. 1차 A/B 선택
7. 선택 이유 입력
8. 결과와 후배 반응 확인
9. 추가 상황 확인
10. 딜레마 재분석 입력
11. 2차 판단 선택
12. 육성 방향 선택
13. AI 프롬프트 복사
14. 외부 AI에 붙여넣기
15. AI 답변을 앱에 붙여넣기
16. 자동분리 결과 확인
17. 필요 시 직접 수정
18. 최종 저장
19. Google Sheets 저장 확인
20. 강사용 대시보드에서 응답 확인

## 5. 자동분리 확인 기준

AI 답변을 붙여넣은 뒤 아래 10개 항목이 채워졌는지 확인합니다.

### 5.1 2주 실행안 5개 항목

- [ ] 2주 뒤 달라졌으면 하는 모습
- [ ] 이번 주에 맡겨볼 작은 일
- [ ] 김원중 과장이 옆에서 도와줄 일
- [ ] 언제 짧게 같이 볼지
- [ ] 말할 때 조심할 표현

### 5.2 코칭 대화문 5줄

- [ ] 먼저 풀어줄 말
- [ ] 바로 답하기 전에 물어볼 말
- [ ] 이번 주에 같이 해볼 일
- [ ] 김원중 과장이 봐줄 선
- [ ] 입 밖으로 내면 안 좋은 말

## 6. fallback 확인 기준

AI 답변에서 코칭 대화문 3번, 4번, 5번이 비어 있거나 `아직 참여하지 않았습니다`로 들어온 경우에도 아래처럼 채워지는지 확인합니다.

| 화면 항목 | 기대 동작 |
|---|---|
| 3. 이번 주에 같이 해볼 일 | `이번 주에 맡겨볼 작은 일` 내용으로 자동 채움 |
| 4. 김원중 과장이 봐줄 선 | `김원중 과장이 옆에서 도와줄 일` 내용으로 자동 채움 |
| 5. 입 밖으로 내면 안 좋은 말 | `말할 때 조심할 표현` 내용으로 자동 채움 |

## 8. 라운드별 내용 확인 포인트

| 라운드 | 확인 포인트 |
|---|---|
| R1 | 확인 의존과 자기 판단 기준이 드러나는가 |
| R2 | 빠른 실행과 기준 점검의 균형이 드러나는가 |
| R5 | 이번 주 행동과 김원중 과장의 개입 경계가 구분되는가 |
| R4 | 출처, 확정 여부, 표현 수위 검증 기준이 드러나는가 |
| R3 | 첫 안내 문장, 넘길 기준, 작은 재진입이 드러나는가 |
| BOSS | 작은 수습 역할과 보고 후 15분 리뷰가 드러나는가 |

## 10. 통과 기준

전체 라운드 테스트는 아래 기준을 만족하면 통과로 봅니다.

- [ ] R1~BOSS 모든 라운드에서 2주 실행안 5개 항목이 분리된다.
- [ ] R1~BOSS 모든 라운드에서 코칭 대화문 5줄이 분리된다.
- [ ] 3번/4번/5번 fallback이 필요한 경우 자동으로 채워진다.
- [ ] 최종 저장이 성공한다.
- [ ] Google Sheets에 저장된다.
- [ ] 강사용 대시보드에서 응답 상세가 보인다.
