# 라운드별 콘텐츠 밀도 균질성 QA

이 문서는 Bridge AI Leadership Journey v2.0의 각 라운드가 같은 수준의 교육적 밀도와 구조를 유지하는지 점검하기 위한 QA 문서입니다.

## 1. QA 목적

라운드별 콘텐츠는 단순히 분량이 비슷하다고 좋은 것이 아닙니다. 교육생이 각 라운드에서 같은 수준의 판단 경험을 하려면 다음 기능이 균형 있게 들어가야 합니다.

- 장면이 구체적으로 보인다.
- 후배의 행동과 말이 드러난다.
- 리더가 흔들릴 만한 압박이 있다.
- A/B 선택 모두 장점과 비용을 가진다.
- 선택 이후 후배 반응이 달라진다.
- 추가 상황이 처음 판단을 다시 보게 만든다.
- 2주 실행안과 5줄 대화문으로 자연스럽게 이어진다.
- 모바일 화면에서 읽기 편하다.

## 2. 밀도 기준

각 라운드는 아래 6개 기준으로 점검합니다.

| 기준 | 설명 | 5점 기준 |
|---|---|---|
| 장면 밀도 | 시간, 장소, 업무 맥락, 현장 압박이 보이는가 | 읽으면 바로 장면이 그려진다 |
| 선택 비용 | A/B 어느 쪽도 완전한 정답이 아니며 각각 비용이 있는가 | 두 선택 모두 장점과 손실이 선명하다 |
| 후배 반응 차별성 | A/B 선택에 따라 후배가 다르게 받아들이는가 | 선택별 감정·해석·다음 행동이 다르다 |
| 추가 상황 압박 | 처음 판단을 다시 보게 만드는 새 변수나 압박이 있는가 | 유지·보완·전환을 고민하게 만든다 |
| 실행안 연결성 | 2주 실행안과 5줄 대화문으로 자연스럽게 이어지는가 | 최종 산출물이 라운드 딜레마를 해결한다 |
| 모바일 가독성 | 짧은 문단, 줄바꿈, 화면 호흡이 적절한가 | 스마트폰에서 읽기 부담이 낮다 |

## 5. 라운드별 진단

### R1. 확인받는 윤동희 사원

**강점**

- 후배의 꼼꼼함과 확인 의존이 분명하게 보입니다.
- A/B 선택 비용이 명확합니다.
- 2주 실행안과 5줄 대화문 연결성이 높습니다.

**보완 필요성**

- 현재는 안정적이므로 큰 수정은 권장하지 않습니다.
- 파일럿에서 “상황이 너무 익숙하다”는 반응이 있으면 압박 변수를 약간 보강합니다.

**현재 판정**

```text
유지
```

### R2. 빠르게 한 황성빈 대리

**강점**

- 대표 테스트 라운드로 가장 균형이 좋습니다.
- 빠른 실행이라는 강점과 기준 누락이라는 비용이 선명합니다.
- 선택별 후배 반응과 실행안 연결이 잘 맞습니다.

**보완 필요성**

- 파일럿에서 가장 많이 사용될 가능성이 높으므로 문구 반응만 추적합니다.

**현재 판정**

```text
유지하되 파일럿 후 미세 조정
```

### R3. 실수 후 위축된 전민재 사원

**강점**

- 정서적 장면과 회복 딜레마가 분명합니다.
- A/B 선택에 따라 위로와 기준 복기의 비용이 달라집니다.
- 후배 반응 차별성은 좋습니다.

**보완 필요성**

- 업무로 재진입하는 작은 역할이 더 구체적이면 좋습니다.
- 민원 응대 상황에서 실제 공항공사 현장 문장과 절차가 더 들어가면 현실성이 올라갑니다.

**v2.1 보완 방향**

```text
첫 안내 문장, 기준 확인, 책임 질문 발생 시 넘길 기준을 더 구체화한다.
```

### R4. AI 초안을 쓴 고승민 대리

**강점**

- AI 활용과 검증 책임이라는 v2.0의 핵심 학습 포인트가 살아 있습니다.
- A/B 선택의 비용이 비교적 선명합니다.
- AI 답변 검토 구조와 잘 연결됩니다.

**보완 필요성**

- 공항공사 실제 대외 안내, 보상 표현, 규정 표현의 현실성을 추가 검토하면 좋습니다.
- 최종 2주 실행안이 “검증 체크리스트”로 더 선명하게 이어지면 좋습니다.

**v2.1 보완 방향**

```text
AI 초안에서 반드시 사람이 확인해야 할 항목을 공항 업무 맥락으로 더 구체화한다.
```

### R5. 더 맡고 싶어 하는 윤동희 사원

**강점**

- 후배의 성장 의욕과 위임 경계라는 좋은 딜레마가 있습니다.
- 코칭 관점과 추천 우선순위는 적용되어 있습니다.
- 5줄 대화문으로 연결되는 구조는 갖추고 있습니다.

**보완 필요성**

- 장면 밀도와 추가 상황 압박이 R1/R2보다 약합니다.
- 유관 부서, 일정 조율, 민원 안내 영향, 상사 보고 압박이 더 들어가면 좋습니다.
- “맡김”과 “방임” 사이의 비용을 더 구체적으로 보여줄 필요가 있습니다.

**파일럿 전 또는 v2.1 보완 방향**

```text
협업부서 답변 지연, 일정 변경, 대외 안내 표현 확정 같은 구체 변수를 추가한다.
```

### BOSS. 보고 직전 수습과 육성

**강점**

- 최종 라운드답게 압박감이 있습니다.
- 긴급 수습과 후배 역할 보존의 충돌이 있습니다.
- 대시보드 토의용으로 활용하기 좋습니다.

**보완 필요성**

- 후배에게 남길 작은 역할을 더 선명하게 하면 좋습니다.
- 보고 후 회복 대화가 더 명확하면 BOSS Round의 학습 완결성이 높아집니다.

**v2.1 보완 방향**

```text
오류 표현 표시, 원문 출처 확인, 수정 근거 한 줄 작성, 보고 후 15분 리뷰를 더 명시한다.
```

## 6. 보완 우선순위

현재 기준에서 밀도 보완 우선순위는 다음과 같습니다.

| 순위 | 라운드 | 이유 |
|---|---|---|
| 1 | R5 | 장면 밀도와 추가 상황 압박이 상대적으로 약함 |
| 2 | BOSS | 최종 라운드 완결성을 높일 여지 있음 |
| 3 | R3 | 재진입 역할을 더 구체화하면 좋음 |
| 4 | R4 | AI 검증 항목의 현실성을 더 높일 수 있음 |
| 유지 | R1/R2 | 현재 균형이 안정적임 |

## 7. R5 보완 체크리스트

R5를 보완할 때는 아래 항목을 추가 또는 강화합니다.

- [ ] 유관 부서 일정 조율 장면이 구체적인가?
- [ ] 후배가 맡고 싶어 하는 이유가 성장 욕구로 보이는가?
- [ ] 일정이 흔들렸을 때 과장에게 올라와야 하는 기준이 있는가?
- [ ] A 선택은 신뢰를 주지만 방임 위험이 있는가?
- [ ] B 선택은 안전선을 주지만 불신으로 들릴 위험이 있는가?
- [ ] 2주 실행안이 위임 경계와 중간 점검으로 연결되는가?
- [ ] 5줄 대화문이 “못 믿어서가 아니라 더 크게 맡기기 위한 기준”을 담고 있는가?

## 8. BOSS 보완 체크리스트

BOSS를 보완할 때는 아래 항목을 추가 또는 강화합니다.

- [ ] 보고 30분 전 압박이 충분히 체감되는가?
- [ ] 후배의 실수와 리더의 수습 책임이 동시에 보이는가?
- [ ] 후배에게 남길 작은 역할이 구체적인가?
- [ ] A 선택은 빠른 수습 대신 후배 배제 비용을 남기는가?
- [ ] B 선택은 학습 기회를 남기지만 보고 리스크를 관리해야 하는가?
- [ ] 보고 후 회복 대화가 실행안으로 이어지는가?
- [ ] 최종 라운드답게 앞 라운드의 학습이 종합되는가?

## 9. 수정 원칙

라운드 밀도를 보완할 때는 다음 원칙을 지킵니다.

1. 상황문만 길게 늘리지 않습니다.
2. 선택 결과와 후배 반응도 함께 조정합니다.
3. 추가 상황은 처음 선택을 다시 보게 만드는 역할을 해야 합니다.
4. 실행안은 반드시 2주 안에 가능한 작은 행동이어야 합니다.
5. 5줄 대화문은 실제 과장이 입 밖으로 낼 수 있어야 합니다.
6. 모든 라운드를 같은 길이로 만들 필요는 없지만, 같은 수준의 판단 압박은 있어야 합니다.
