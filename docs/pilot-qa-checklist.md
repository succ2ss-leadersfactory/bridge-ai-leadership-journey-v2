# Bridge AI Leadership Journey v2.0 파일럿 QA 체크리스트

이 문서는 Vercel 배포 후 교육생 스마트폰 화면과 강사용 PC 대시보드를 점검하기 위한 체크리스트입니다.

## 1. 기본 접속 확인

- [ ] 교육생 URL에 접속하면 모바일 폭 화면이 정상 표시된다.
- [ ] 강사용 대시보드 URL에 접속하면 PC 화면이 정상 표시된다.
- [ ] 새로고침 후에도 화면이 깨지지 않는다.
- [ ] 뒤로가기/다음 버튼이 하단 고정 영역에서 정상 표시된다.

## 2. 입장 화면 확인

- [ ] 팀명 입력칸이 보인다.
- [ ] 닉네임 입력칸이 보인다.
- [ ] 팀명과 닉네임을 입력하기 전에는 다음 이동이 제한된다.
- [ ] 입력 후 세션 Map으로 이동한다.
- [ ] 입장 화면과 세션 Map이 분리되어 보인다.

## 3. 세션 Map 확인

- [ ] Session 1, Session 2, Session 3이 모두 보인다.
- [ ] Session 1 제목이 `후배를 읽고 기준을 남기다`로 표시된다.
- [ ] Session 2 제목이 `시도를 성장 경험으로 바꾸다`로 표시된다.
- [ ] Session 3 제목이 `맡기고 수습 속에서도 키우다`로 표시된다.
- [ ] 세션을 선택하면 선택 표시가 보인다.
- [ ] 선택 후 해당 세션의 라운드 Map으로 이동한다.

## 4. 세션별 라운드 Map 확인

- [ ] Session 1을 선택하면 R1, R2만 보인다.
- [ ] Session 2를 선택하면 R3, R4만 보인다.
- [ ] Session 3을 선택하면 R5, Boss Round만 보인다.
- [ ] 라운드 카드에 후배 이름과 지금 도와줄 일이 표시된다.
- [ ] 저장 완료된 라운드에는 완료 뱃지가 표시된다.
- [ ] 라운드 Map에서 뒤로 가면 세션 Map으로 돌아간다.

## 5. R2 대표 흐름 확인

R2는 `2주 기준 점검 루틴 플랜` 반영 여부를 확인하기 위한 대표 테스트 라운드다.

- [ ] Session 1에서 R2를 선택할 수 있다.
- [ ] R2 제목이 정상 표시된다.
- [ ] 후배 이름이 황성빈 대리로 표시된다.
- [ ] 후배 행동 읽기 화면에서 입력 후 다음으로 이동된다.
- [ ] 1차 선택 A/B와 선택 이유 입력이 정상 작동한다.
- [ ] 선택 결과 화면이 정상 표시된다.
- [ ] 후배 반응 화면이 정상 표시된다.
- [ ] 걸리는 지점 입력 후 다음으로 이동된다.
- [ ] 다시 보기 선택이 정상 작동한다.
- [ ] 추가 상황 화면이 정상 표시된다.
- [ ] 2주 도움 고르기 화면에서 하나를 선택할 수 있다.

## 6. AI 프롬프트 확인

- [ ] AI에게 물어볼 말 화면이 정상 표시된다.
- [ ] 프롬프트 안에 선택한 라운드, 선택 이유, 후배 반응, 다시 판단, 육성 방향이 포함된다.
- [ ] R2 프롬프트 안에 `2주 기준 점검 루틴 플랜` 문구가 포함된다.
- [ ] 프롬프트 안에서 `주임`이 아니라 `대리`로 표시된다.
- [ ] 프롬프트 복사 버튼이 작동한다.
- [ ] 복사 후 성공 메시지가 표시된다.
- [ ] 프롬프트 수정 후에도 다음으로 이동된다.

## 7. AI 답변 붙여넣기 확인

- [ ] 외부 AI 답변 전체를 붙여넣을 수 있다.
- [ ] FINAL_ARTIFACT 블록이 있으면 AI 초안 영역에 분리 표시된다.
- [ ] REVIEW_NOTES 블록이 있으면 한 번 더 생각해 볼 점 영역에 분리 표시된다.
- [ ] 그대로 참고할 부분을 입력할 수 있다.
- [ ] 고쳐야 할 부분을 입력할 수 있다.
- [ ] 그대로 쓰면 위험한 부분을 입력할 수 있다.
- [ ] 세 항목 중 하나 이상 입력해야 다음으로 이동된다.

## 8. 2주 실행안과 후배에게 할 말 확인

- [ ] 2주 실행안 화면 제목이 라운드별 최종 산출물명으로 표시된다.
- [ ] R2는 `2주 기준 점검 루틴 플랜`으로 표시된다.
- [ ] `2주 뒤 보고 싶은 작은 변화`를 입력할 수 있다.
- [ ] `이번 주 맡겨볼 작은 행동`을 입력할 수 있다.
- [ ] `과장이 도와줄 방식`을 입력할 수 있다.
- [ ] 위 3개 항목을 입력하면 다음으로 이동된다.
- [ ] 내일 할 말 화면은 1~5번째 개별 입력칸이 아니라 하나의 편집창으로 보인다.
- [ ] 후배에게 할 말은 3줄 이상 입력하면 결과 화면으로 이동된다.

## 9. 저장 확인

- [ ] 결과 화면에서 저장 전에는 라운드 Map으로 돌아가기 버튼이 비활성화된다.
- [ ] 결과 화면에는 3개 핵심 실행안과 후배에게 할 말이 표시된다.
- [ ] 작성한 내용 저장하기 버튼을 누르면 저장 중 메시지가 표시된다.
- [ ] 저장 성공 후 저장 완료 상태가 표시된다.
- [ ] 저장 성공 후 라운드 Map으로 돌아가기 버튼이 활성화된다.
- [ ] 라운드 Map으로 돌아가면 해당 라운드에 완료 뱃지가 표시된다.
- [ ] 저장 실패 시 완료 뱃지가 표시되지 않는다.

## 10. Google Sheets 확인

- [ ] Participants 시트에 팀명과 닉네임이 저장된다.
- [ ] Responses 시트에 round_id가 저장된다.
- [ ] Responses 시트에 junior_reading이 저장된다.
- [ ] Responses 시트에 first_choice와 first_reason이 저장된다.
- [ ] Responses 시트에 development_dilemma가 저장된다.
- [ ] Responses 시트에 second_choice가 저장된다.
- [ ] Responses 시트에 generated_prompt와 edited_prompt가 저장된다.
- [ ] Responses 시트에 AI 검토 항목 3개가 저장된다.
- [ ] Responses 시트에 2주 실행안 핵심 항목이 저장된다.
- [ ] Responses 시트에 final_line_1~5 중 입력한 줄이 저장된다.
- [ ] is_completed가 TRUE 또는 이에 준하는 완료값으로 저장된다.

## 11. 강사용 대시보드 확인

- [ ] 새로고침 버튼이 작동한다.
- [ ] 저장된 팀명이 표시된다.
- [ ] 저장된 닉네임이 표시된다.
- [ ] 세션별 응답 현황 카드가 보인다.
- [ ] Session 1, Session 2, Session 3 응답 수가 반영된다.
- [ ] 라운드별 응답 분포가 표시된다.
- [ ] 저장된 라운드가 표시된다.
- [ ] 라운드명에서 `주임`이 아니라 `대리`로 표시된다.
- [ ] 완료 수가 반영된다.
- [ ] 상세 펼침에서 세션명이 표시된다.
- [ ] 상세 펼침에서 2주 실행안과 후배에게 할 말이 확인된다.

## 12. 스마트폰 사용성 확인

- [ ] Android Chrome에서 입력칸이 정상 작동한다.
- [ ] iPhone Safari에서 입력칸이 정상 작동한다.
- [ ] 긴 AI 답변을 붙여넣어도 화면이 깨지지 않는다.
- [ ] 하단 버튼이 키보드에 가려지지 않는지 확인한다.
- [ ] 뒤로가기 후 입력값이 유지된다.
- [ ] 새로고침 후 임시 저장값이 복원된다.

## 13. 파일럿 운영 전 최종 판단

- [ ] 교육생 1명이 R2 전체 흐름을 10분 안에 완료할 수 있다.
- [ ] 세션 Map에서 오늘 진행할 세션을 쉽게 찾을 수 있다.
- [ ] 강사가 대시보드에서 저장 결과를 1분 안에 확인할 수 있다.
- [ ] 참여자가 AI 프롬프트를 읽고 수정할 수 있다.
- [ ] 참여자가 AI 답변을 그대로 쓰지 않고 골라보는 흐름을 이해한다.
- [ ] 마지막 입력 화면이 과제처럼 느껴지지 않고 실행안 정리처럼 보인다.
- [ ] 저장 실패 시 강사가 대체 입력 또는 재시도 안내를 할 수 있다.
