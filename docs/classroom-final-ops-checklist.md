# 교육 당일 최종 운영 체크리스트

이 문서는 한국공항공사 Bridge AI Leadership Journey v2.0을 교육장에서 운영하기 위한 최종 체크리스트입니다.

## 1. 교육 시작 30분 전

### 1.1 운영 환경

- [ ] 강사용 PC 또는 태블릿에서 Vercel 앱 주소에 접속한다.
- [ ] `/?view=check` 사전 점검 화면을 연다.
- [ ] `Vercel 환경변수` 카드가 정상인지 확인한다.
- [ ] `시트/헤더 점검` 버튼을 눌러 Participants, Responses 시트를 확인한다.
- [ ] `조회 테스트` 버튼을 눌러 Google Sheets 데이터 조회가 되는지 확인한다.
- [ ] 강사용 대시보드 `/?view=instructor`가 정상으로 열린다.
- [ ] 교육생용 QR 코드 또는 URL이 준비되어 있다.

### 1.2 Google Sheets

- [ ] Google Sheets 파일을 열어둔다.
- [ ] Participants 시트가 있다.
- [ ] Responses 시트가 있다.
- [ ] Responses 시트에 `check_timing`, `watch_out`, `final_line_1~5` 컬럼이 있다.
- [ ] 필요하면 테스트 데이터는 별도 표시하거나 삭제한다.

### 1.3 강사용 대시보드

- [ ] `데이터 새로고침` 버튼이 작동한다.
- [ ] 참여자 수, 전체 응답 수, 완료 응답 수, 참여 팀 수 카드가 보인다.
- [ ] 최근 저장 응답 상세 펼침이 작동한다.
- [ ] 5개 실행계획과 5줄 대화문이 상세에서 보이는지 확인한다.

## 2. 교육 시작 10분 전

### 2.1 참여자 접속 안내

- [ ] 교육생에게 QR 코드 또는 URL을 안내한다.
- [ ] 팀명은 강사가 지정한 팀명으로 입력하게 한다.
- [ ] 닉네임은 교육 중 부를 이름으로 입력하게 한다.
- [ ] 접속이 안 되는 교육생은 같은 팀의 다른 기기로 대표 입력하게 한다.

### 2.2 첫 화면 확인

- [ ] 교육생들이 팀명/닉네임 입력 화면을 보고 있다.
- [ ] 팀명과 닉네임 입력 후 세션 Map으로 이동한다.
- [ ] 세션 Map에서 Session 1, Session 2, Session 3이 보인다.

## 3. 실습 진행 중

### 3.1 라운드 시작 전

- [ ] 오늘 진행할 세션과 라운드를 강사가 명확히 안내한다.
- [ ] 정답형 점수 게임이 아니라 판단 연습임을 안내한다.
- [ ] AI는 정답 제공자가 아니라 판단을 정교화하는 보조 도구임을 안내한다.

### 3.2 AI 프롬프트 단계

- [ ] 교육생이 자동 생성된 프롬프트를 전체로 읽어본다.
- [ ] 자신의 판단과 다른 부분은 수정하게 한다.
- [ ] 프롬프트 복사 후 외부 AI에 붙여넣게 한다.
- [ ] AI 답변을 그대로 믿지 말고 앱에 다시 붙여넣게 한다.

### 3.3 AI 답변 검토 단계

- [ ] 자동분리에서 10개 항목이 잡혔는지 확인하게 한다.
- [ ] 누락 항목이 있으면 다음 화면에서 직접 채우면 된다고 안내한다.
- [ ] `쓸 말`, `고칠 말`, `뺄 말` 중 최소 하나는 반드시 입력하게 한다.

### 3.4 최종 실행안 단계

- [ ] 2주 실행안 5개 항목을 실제 행동 단위로 고치게 한다.
- [ ] 5줄 대화문은 실제 후배 앞에서 말할 수 있는 문장으로 고치게 한다.
- [ ] 저장 전 최종 화면에서 전체 내용을 확인하게 한다.

## 4. 저장 확인

- [ ] 교육생이 `최종본 저장하기`를 누른다.
- [ ] 저장 완료 메시지를 확인한다.
- [ ] 라운드 Map으로 돌아가 완료 뱃지를 확인한다.
- [ ] 강사용 대시보드에서 `데이터 새로고침`을 누른다.
- [ ] 팀별 저장 응답이 표시되는지 확인한다.
- [ ] 최근 저장 응답을 펼쳐 5개 실행안과 5줄 대화문을 확인한다.

## 5. 강사용 토의 활용

대시보드에서 다음 질문을 활용한다.

1. 같은 상황에서 첫 선택이 왜 갈렸을까요?
2. AI 답변 중 그대로 쓰기 위험한 표현은 무엇이었나요?
3. 2주 실행안 중 실제로 확인 가능한 행동은 무엇인가요?
4. 후배에게 말할 때 가장 조심해야 할 표현은 무엇인가요?
5. 과장이 직접 처리하는 것과 후배를 키우는 것 사이의 균형은 어디에서 갈렸나요?

## 6. 장애 발생 시 대체 운영

| 상황 | 조치 |
|---|---|
| 일부 교육생 접속 실패 | 같은 팀 대표 1명이 입력 |
| 저장 실패 | 최종 화면 캡처 후 강사가 대시보드 대신 구두 공유 |
| AI 답변 자동분리 실패 | 필요한 문장을 직접 복사해 입력 |
| 강사용 대시보드 조회 실패 | Google Sheets Responses 시트를 직접 확인 |
| 전체 네트워크 불안정 | 강사가 화면 시연 후 종이/메모 앱으로 대체 |

## 7. 교육 종료 전

- [ ] 각 팀이 최소 1개 라운드를 저장했다.
- [ ] 강사용 대시보드에서 전체 응답 수가 확인된다.
- [ ] 좋은 실행안 1~2개를 강사가 선택해 공유한다.
- [ ] 교육생에게 최종 5줄 대화문을 실제 현장에 가져가도록 안내한다.
- [ ] Google Sheets 데이터를 백업한다.

## 8. 최종 운영 판정

아래 5개가 통과되면 정상 운영으로 판단한다.

- [ ] Preflight 점검 정상
- [ ] 교육생 화면 접속 정상
- [ ] AI 프롬프트 복사 정상
- [ ] Google Sheets 저장 정상
- [ ] 강사용 대시보드 조회 정상
