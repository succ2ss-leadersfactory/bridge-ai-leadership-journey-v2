# Bridge AI Leadership Journey v2.0 최종 릴리즈 노트

이 문서는 한국공항공사 Bridge AI Leadership Journey v2.0 파일럿 운영 전 최종 반영 사항과 점검 순서를 정리한 릴리즈 노트입니다.

## 1. 릴리즈 목적

Bridge AI Leadership Journey v2.0은 한국공항공사 과장급 중간관리자가 후배의 행동을 읽고, 육성 딜레마를 판단하며, AI를 활용해 2주 실행안과 실제 대화 문장을 정리하는 교육용 웹앱입니다.

이번 릴리즈의 목적은 다음입니다.

- 교육생 모바일 실습 흐름 안정화
- 강사용 대시보드 운영성 강화
- Google Sheets 저장 연동 안정화
- 라운드별 콘텐츠 보완 기준 전체 적용
- 라운드별 콘텐츠 밀도 균질화
- 파일럿 운영 문서와 점검 절차 정리

## 2. 현재 배포 상태

최신 주요 기능 커밋 기준 Vercel 배포는 success로 확인되었습니다.

```text
라운드 콘텐츠 밀도 보완: success
R3 재진입 역할 구체화: success
R4 AI 검증 현실성 보완: success
R5 위임 경계 밀도 보완: success
BOSS 최종 라운드 완결성 보완: success
대시보드 고도화: success
Preflight 점검 기능: success
```

운영 전에는 Vercel 프로젝트에서 최신 배포가 `Ready` 상태인지 한 번 더 확인합니다.

## 4. 학습자 흐름 최종 구조

```text
입장
→ 세션 선택
→ 라운드 선택
→ 상황 읽기
→ 후배 행동 읽기
→ 1차 대응 선택
→ 선택 결과 확인
→ 후배 반응 확인
→ 추가 상황 확인
→ 딜레마 재분석
→ 2차 판단 선택
→ 육성 방향 선택
→ AI 프롬프트 생성·수정·복사
→ AI 답변 붙여넣기·검토
→ 2주 실행안 5개 항목 작성
→ 후배에게 실제로 할 말 5줄 작성
→ 최종 저장
```

## 7. 라운드 콘텐츠 최종 보완 현황

| 라운드 | 보완 상태 |
|---|---|
| R1 | 확인 의존과 자기 판단 기준 딜레마 유지 |
| R2 | 빠른 실행과 기준 점검 딜레마 유지 |
| R3 | 실패 후 위축된 후배의 첫 안내 문장, 넘길 기준, 작은 재진입 역할 구체화 완료 |
| R4 | AI 초안의 출처, 확정 여부, 표현 수위 검증 기준 보완 완료 |
| R5 | 유관 부서 일정 조율, 배포일 변경, 위임 경계 보완 완료 |
| BOSS | 보고 직전 압박, 작은 수습 역할, 보고 후 15분 리뷰 보완 완료 |

## 8. 최근 주요 반영 사항

### 8.1 라운드 콘텐츠

- R2의 선택 결과와 후배 반응 고도화 누락 보완
- R3의 회복 장면을 첫 안내 문장, 넘길 기준, 동행 후 단독 시도 구조로 구체화
- R4의 AI 초안 검증 기준을 출처, 확정 여부, 표현 수위 중심으로 보완
- R5의 위임 장면에 유관 부서 일정 조율, 안내문 배포, 현장 표현 리스크를 추가
- BOSS 라운드에 오류 표현 표시, 원문 출처 확인, 수정 근거 한 줄 작성, 보고 후 15분 리뷰를 추가
- `aiPromptTemplate` 내 오래된 3~5줄 표현을 5줄 기준으로 정규화
- 라운드별 콘텐츠 적용 레이어 맵과 밀도 QA 문서화

### 8.2 AI 활용 흐름

- AI 프롬프트 출력 형식을 5개 실행계획 + 5줄 대화문 기준으로 정렬
- AI 답변 자동분리 기준을 10개 항목으로 정리
- AI 답변 검토 항목을 `참고할 부분 / 고칠 부분 / 조심할 부분`으로 순화

### 8.3 저장 연동

- Apps Script `saveLearnerResultV2` 저장 endpoint 안정화
- `LockService`로 동시 저장 충돌 가능성 완화
- `setupSheetsV2`로 시트와 헤더 사전 점검 가능
- `getDashboardDataV2`로 강사용 대시보드 조회 가능

### 8.4 강사용 대시보드

- 첫 선택 분포 추가
- 다시 잡은 판단 분포 추가
- 강사용 토의 질문 카드 추가
- 최근 저장 응답 상세에 선택 흐름, AI 검토, 2주 실행안, 5줄 대화문, 토의 힌트 표시

### 8.5 운영 문서

- 태블릿 Preflight 점검 가이드 추가
- 수동 테스트 스크립트 업데이트
- 파일럿 QA 체크리스트 업데이트
- 교육 당일 운영 체크리스트 추가
- 강사용 당일 진행 멘트 추가
- 콘텐츠 줄바꿈 정책 문서 추가
- 라운드별 콘텐츠 레이어 맵 추가
- 라운드별 콘텐츠 밀도 QA 문서 추가

## 9. 운영 전 필수 점검 순서

### 9.1 Preflight 점검

운영 전 아래 화면을 엽니다.

```text
/?view=check
```

확인 순서:

1. Vercel 환경변수 카드가 정상인지 확인
2. `시트/헤더 점검` 실행
3. Participants, Responses 시트 확인
4. `조회 테스트` 실행
5. 교육생 화면 링크 확인
6. 강사용 대시보드 링크 확인

### 9.2 테스트 라운드 저장

권장 테스트 경로:

```text
Session 1 → R2
```

확인할 것:

- AI 프롬프트 복사 성공
- AI 답변 붙여넣기 후 10개 항목 자동분리
- 2주 실행안 5개 항목 표시
- 5줄 대화문 표시
- 최종 저장 성공
- 라운드 Map 완료 뱃지 표시
- Google Sheets Responses 시트 저장 확인
- 강사용 대시보드에서 응답 확인

### 9.3 콘텐츠 밀도 확인

추가로 아래 라운드는 스마트폰에서 직접 열어 가독성을 확인합니다.

| 라운드 | 확인 포인트 |
|---|---|
| R3 | 첫 안내 문장과 넘길 기준이 이해되는지 |
| R4 | 출처, 확정 여부, 표현 수위 검증 기준이 보이는지 |
| R5 | 위임 경계와 일정 조율 리스크가 보이는지 |
| BOSS | 작은 수습 역할과 보고 후 리뷰가 보이는지 |

## 11. 알려진 주의사항

### 11.1 R5/BOSS 콘텐츠 관리 위치

R5와 BOSS는 R1~R4처럼 모든 본문이 `roundOverrides.ts`에 모여 있지 않습니다. 기본 원형은 `rounds.ts`에 있고, 최종 보정은 여러 override 파일에 분산되어 있습니다.

수정 시 반드시 아래 문서를 먼저 확인합니다.

```text
docs/round-content-layer-map.md
```

### 11.2 Apps Script 최신화

GitHub의 `apps-script/Code.gs`를 Google Sheets 바운드 Apps Script에 실제로 붙여넣고 새 배포해야 저장 연동 최신 기능이 작동합니다.
