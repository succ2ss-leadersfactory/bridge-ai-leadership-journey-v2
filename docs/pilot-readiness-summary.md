# Bridge AI Leadership Journey v2.0 파일럿 준비 요약

이 문서는 파일럿 운영 직전에 강사와 운영자가 현재 앱 상태, 점검 문서, 필수 테스트 흐름을 빠르게 확인하기 위한 요약본입니다.

## 1. 현재 앱 상태

현재 v2.0은 후배육성 Lab 웹앱으로, 교육생 모바일 화면과 강사용 PC 대시보드가 분리되어 있습니다.

교육생은 스마트폰에서 세션을 선택하고, 세션별 2개 라운드 중 하나를 진행합니다. 이후 AI 프롬프트를 복사해 외부 AI 도구에서 답변을 받아보고, 그 결과를 골라보며 2주 실행안과 후배에게 할 말을 정리합니다.

강사는 PC 대시보드에서 팀별, 세션별, 라운드별 응답 현황과 최근 저장 응답을 확인합니다.

## 2. 현재 학습 흐름

```text
입장
→ 세션 Map
→ 세션별 라운드 Map
→ 상황 읽기
→ 후배 행동 읽기
→ 1차 판단
→ 선택 결과 확인
→ 후배 반응 확인
→ 육성 딜레마 정리
→ 다시 판단
→ 추가 상황 확인
→ 2주 도움 고르기
→ AI 프롬프트 수정 및 복사
→ AI 답변 골라보기
→ 2주 실행안 3개 작성
→ 후배에게 할 말 3~5줄 작성
→ 저장
→ 강사용 대시보드 확인
```

## 3. 세션 구조

| 세션 | 핵심 주제 | 포함 라운드 | 강사 리뷰 초점 |
|---|---|---|---|
| Session 1 | 후배를 읽고 기준을 남기다 | R1, R2 | 행동 신호, 판단 기준, 점검 루틴 |
| Session 2 | 시도를 성장 경험으로 바꾸다 | R3, R4 | 회복, 멘토링, 검증 책임 |
| Session 3 | 맡기고 수습 속에서도 키우다 | R5, Boss Round | 위임 경계, 점검, 작은 역할 남기기 |

## 4. 호칭 기준

모든 인물은 성과 이름, 직급을 함께 씁니다.

```text
김민재 사원
이서연 대리
정하늘 사원
최도윤 대리
```

허용 직급은 다음으로 통일합니다.

```text
사원 / 대리 / 과장
```

## 5. 파일럿 전 필수 테스트

대표 테스트는 Session 1의 R2로 진행합니다.

- [ ] 스마트폰에서 교육생 화면이 열린다.
- [ ] 팀명과 닉네임 입력 후 세션 Map으로 이동한다.
- [ ] Session 1을 선택하면 R1, R2만 보인다.
- [ ] R2에서 이서연 대리로 표시된다.
- [ ] AI 프롬프트가 자동 생성되고 수정할 수 있다.
- [ ] 프롬프트 복사가 작동한다.
- [ ] AI 답변을 붙여넣고 골라볼 수 있다.
- [ ] 2주 실행안은 3개 입력칸으로 보인다.
- [ ] 후배에게 할 말은 하나의 편집창으로 보인다.
- [ ] 작성한 내용 저장하기가 작동한다.
- [ ] 저장 후 라운드 완료 뱃지가 표시된다.
- [ ] Google Sheets에 응답이 저장된다.
- [ ] 강사용 대시보드에 세션별, 라운드별, 팀별 응답이 표시된다.

## 7. 파일럿 운영 시 권장 흐름

1. 강사가 세션 주제를 2~3분 소개한다.
2. 교육생이 세션 안의 2개 라운드를 체험한다.
3. 팀별로 선택 이유와 AI 답변에서 고친 부분을 공유한다.
4. 강사가 세션별 핵심 개념을 미니 강의로 정리한다.
5. 교육생이 2주 실행안과 후배에게 할 말을 저장한다.
6. 강사는 대시보드에서 세션별·라운드별 응답을 보며 토의를 마무리한다.

## 8. 파일럿 중 주의할 점

- 이 웹앱은 정답형 퀴즈가 아니다.
- 선택 결과는 점수화하지 않는다.
- 후배를 의존형, 소심형, 문제형처럼 낙인찍지 않는다.
- AI 답변은 그대로 쓰지 않고 골라보고 고쳐 쓰게 한다.
- 마지막 실행안은 멋진 문장이 아니라 다음 주 현장에서 실제로 해볼 수 있는 행동이어야 한다.

## 9. 파일럿 통과 기준

아래 기준을 충족하면 파일럿 운영이 가능하다고 판단합니다.

- [ ] R2 전체 흐름을 10분 안에 완료할 수 있다.
- [ ] 스마트폰에서 입력과 복사가 안정적으로 작동한다.
- [ ] 저장 후 Google Sheets와 대시보드가 1분 안에 갱신된다.
- [ ] 강사가 세션별 응답 현황을 보고 토의에 활용할 수 있다.
- [ ] 참여자가 마지막 입력을 과제가 아니라 실행안 정리로 받아들인다.
