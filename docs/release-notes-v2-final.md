# Bridge AI Leadership Journey v2.0 최종 릴리즈 노트

이 문서는 한국공항공사 Bridge AI Leadership Journey v2.0 파일럿 운영 전 최종 반영 사항과 점검 순서를 정리한 릴리즈 노트입니다.

## 1. 릴리즈 목적

Bridge AI Leadership Journey v2.0은 한국공항공사 과장급 중간관리자가 후배의 행동을 읽고, 육성 딜레마를 판단하며, AI를 활용해 2주 실행안과 실제 대화 문장을 정리하는 교육용 웹앱입니다.

이번 릴리즈의 목적은 다음입니다.

- 교육생 모바일 실습 흐름 안정화
- 강사용 대시보드 운영성 강화
- Google Sheets 저장 연동 안정화
- 라운드별 콘텐츠 보완 기준 전체 적용
- 파일럿 운영 문서와 점검 절차 정리

## 2. 현재 배포 상태

최신 주요 기능 커밋 기준 Vercel 배포는 success로 확인되었습니다.

```text
R3~BOSS 수동 줄바꿈 보정: success
대시보드 고도화: success
Preflight 점검 기능: success
라운드 콘텐츠 보완 주요 커밋: success 또는 문서 변경 pending 후 영향 낮음
```

운영 전에는 Vercel 프로젝트에서 최신 배포가 `Ready` 상태인지 한 번 더 확인합니다.


## 8. 최근 주요 반영 사항

### 8.1 라운드 콘텐츠

- R2의 선택 결과와 후배 반응 고도화 누락 보완
- R3~BOSS 수동 줄바꿈 보정 추가
- `aiPromptTemplate` 내 오래된 3~5줄 표현을 5줄 기준으로 정규화
- 라운드별 콘텐츠 적용 레이어 맵 문서화

### 8.2 AI 활용 흐름

- AI 프롬프트 출력 형식을 5개 실행계획 + 5줄 대화문 기준으로 정렬
- AI 답변 자동분리 기준을 10개 항목으로 정리
- AI 답변 검토 항목을 `참고할 부분 / 고칠 부분 / 조심할 부분`으로 순화

### 8.3 저장 연동

- Apps Script `saveLearnerResultV2` 저장 endpoint 안정화
- `LockService`로 동시 저장 충돌 가능성 완화
- `setupSheetsV2`로 시트와 헤더 사전 점검 가능
- `getDashboardDataV2`로 강사용 대시보드 조회 가능

### 8.4 강사용 대시보드

- 첫 선택 분포 추가
- 다시 잡은 판단 분포 추가
- 강사용 토의 질문 카드 추가
- 최근 저장 응답 상세에 선택 흐름, AI 검토, 2주 실행안, 5줄 대화문, 토의 힌트 표시

### 8.5 운영 문서

- 태블릿 Preflight 점검 가이드 추가
- 수동 테스트 스크립트 업데이트
- 파일럿 QA 체크리스트 업데이트
- 교육 당일 운영 체크리스트 추가
- 강사용 당일 진행 멘트 추가
- 콘텐츠 줄바꿈 정책 문서 추가
- 라운드별 콘텐츠 레이어 맵 추가

## 9. 운영 전 필수 점검 순서

### 9.1 Preflight 점검

운영 전 아래 화면을 엽니다.

```text
/?view=check
```

확인 순서:

1. Vercel 환경변수 카드가 정상인지 확인
2. `시트/헤더 점검` 실행
3. Participants, Responses 시트 확인
4. `조회 테스트` 실행
5. 교육생 화면 링크 확인
6. 강사용 대시보드 링크 확인

### 9.2 테스트 라운드 저장

권장 테스트 경로:

```text
Session 1 → R2
```

확인할 것:

- AI 프롬프트 복사 성공
- AI 답변 붙여넣기 후 10개 항목 자동분리
- 2주 실행안 5개 항목 표시
- 5줄 대화문 표시
- 최종 저장 성공
- 라운드 Map 완료 뱃지 표시
- Google Sheets Responses 시트 저장 확인
- 강사용 대시보드에서 응답 확인

## 11. 알려진 주의사항

### 11.1 R5/BOSS 콘텐츠 관리 위치

R5와 BOSS는 R1~R4처럼 모든 본문이 `roundOverrides.ts`에 모여 있지 않습니다. 기본 원형은 `rounds.ts`에 있고, 최종 보정은 여러 override 파일에 분산되어 있습니다.

수정 시 반드시 아래 문서를 먼저 확인합니다.

```text
docs/round-content-layer-map.md
```

### 11.2 문서 변경 커밋의 Vercel 상태

문서만 수정한 커밋은 Vercel이 pending으로 보일 수 있으나, 앱 기능 영향은 낮습니다. TypeScript 파일을 수정한 기능 커밋은 반드시 success 여부를 확인합니다.

### 11.3 Apps Script 최신화

GitHub의 `apps-script/Code.gs`를 Google Sheets 바운드 Apps Script에 실제로 붙여넣고 새 배포해야 저장 연동 최신 기능이 작동합니다.
