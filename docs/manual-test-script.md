# Bridge AI Leadership Journey v2.0 수동 테스트 스크립트

이 문서는 교육장 파일럿 전에 학습자 화면, AI 답변 붙여넣기, Google Sheets 저장, 강사용 대시보드 표시를 한 번에 검증하기 위한 수동 테스트 절차입니다.

## 1. 테스트 URL

| 화면 | 접속 경로 |
|---|---|
| 교육생 화면 | `/` |
| 강사용 대시보드 | `/?view=instructor` |
| 사전 점검 화면 | `/?view=check` |

## 2. 테스트 전 준비

- [ ] Vercel 최신 배포 상태가 `success`인지 확인한다.
- [ ] Vercel 환경변수 `VITE_GOOGLE_SCRIPT_WEBAPP_URL`이 등록되어 있는지 확인한다.
- [ ] Google Sheets에 `Participants`, `Responses` 시트가 있거나 Apps Script가 자동 생성할 수 있는지 확인한다.
- [ ] 강사용 PC에서 `/?view=instructor`에 접속 가능해야 한다.
- [ ] 교육생 스마트폰 또는 태블릿에서 `/`에 접속 가능해야 한다.

## 3. 사전 점검 화면 테스트

`/?view=check`에 접속한다.

확인할 것:

- [ ] 환경변수 카드가 정상으로 표시된다.
- [ ] `시트/헤더 점검` 버튼을 누르면 Participants, Responses 시트가 확인된다.
- [ ] 시트/헤더 점검 결과에 확인된 시트 수와 컬럼 수가 표시된다.
- [ ] `조회 테스트` 버튼을 누르면 Google Sheets 데이터 조회가 성공한다.
- [ ] 현재 조회된 참여자 수와 응답 수가 표시된다.
- [ ] 교육생 화면 열기 링크가 정상 작동한다.
- [ ] 강사용 대시보드 열기 링크가 정상 작동한다.

## 4. 교육생 화면 테스트 절차

### 4.1 입장

| 항목 | 테스트 입력 |
|---|---|
| 팀명 | 테스트1팀 |
| 닉네임 | 김테스트 |

확인할 것:

- [ ] 팀명과 닉네임 입력 전에는 다음 버튼이 활성화되지 않는다.
- [ ] 입력 후 세션 Map으로 이동한다.
- [ ] 새로고침하면 입력값이 유지된다.

### 4.2 세션과 라운드 선택

권장 테스트 경로:

```text
Session 1 → R2
```

확인할 것:

- [ ] Session 1에는 R1, R2만 보인다.
- [ ] R2에 황성빈 대리가 표시된다.
- [ ] 라운드 선택 후 상황 화면으로 이동한다.

### 4.3 라운드 판단 흐름 입력

아래 값으로 빠르게 입력한다.

| 단계 | 테스트 입력 |
|---|---|
| 후배 행동 읽기 | 황성빈 대리는 기준을 확인받고 싶어 하는 것으로 보인다. |
| 1차 선택 이유 | 빠르게 진행하는 점은 인정하되, 공유 전 기준 확인은 남기고 싶다. |
| 다시 봐야 할 지점 | 기준을 세우게 하려다 차갑게 느껴질 수 있고, 일정 압박도 함께 봐야 한다. |

확인할 것:

- [ ] 필수 입력 전에는 다음 단계로 이동할 수 없다.
- [ ] A/B 선택이 정상 작동한다.
- [ ] 유지/보완/전환 선택이 정상 작동한다.
- [ ] 육성 방향 선택 후 AI 프롬프트 화면으로 이동한다.

## 5. AI 프롬프트 복사 테스트

확인할 것:

- [ ] 프롬프트 안에 팀장 역할, 라운드 상황, 후배 행동 읽기, 1차 선택, 다시 판단, 육성 방향이 포함된다.
- [ ] 복사 버튼을 누르면 성공 메시지가 표시된다.
- [ ] 프롬프트를 수정해도 다음 단계로 이동할 수 있다.

## 6. AI 답변 붙여넣기 테스트용 샘플

아래 샘플을 그대로 AI 답변 붙여넣기 칸에 입력한다.

```text
<FINAL_ARTIFACT>
1. 2주 기준 점검 루틴 플랜
- 2주 뒤 달라졌으면 하는 모습: 황성빈 대리가 질문하기 전에 자신이 본 기준과 1차 의견을 먼저 말한다.
- 이번 주에 맡겨볼 작은 일: 이번 주 안내 문구 2건을 가져올 때 제가 본 기준, 제 1차 의견, 같이 확인받고 싶은 부분을 세 줄로 정리해 온다.
- 김원중 과장이 옆에서 도와줄 일: 처음 두 번은 김원중 과장이 기준을 같이 보고, 세 번째부터는 황성빈 대리가 먼저 판단한 뒤 필요한 부분만 확인한다.
- 언제 짧게 같이 볼지: 화요일과 목요일 오후에 10분씩 실제 문구를 놓고 혼자 볼 일과 같이 볼 일을 구분한다.
- 말할 때 조심할 표현: 속도 자체를 문제 삼는 말보다, 빠른 실행 뒤에 확인 기준을 붙이자는 말로 설명한다.

2. 후배 코칭 대화문 5줄
1) 먼저 풀어줄 말: 황성빈 대리, 빠르게 초안을 잡아준 점은 분명 도움이 됐어요.
2) 바로 답하기 전에 물어볼 말: 이번 자료는 공유 대상이 바뀌면서 어떤 기준을 다시 봐야 한다고 생각했어요?
3) 이번 주에 같이 해볼 일: 이번 주 자료 2건은 문서 상단에 공유 대상과 기준일을 먼저 표시해 봅시다.
4) 김원중 과장이 봐줄 선: 처음 두 번은 제가 기준일과 표현 수위만 같이 보고, 그다음부터는 황성빈 대리가 먼저 판단해 봅시다.
5) 입 밖으로 내면 안 좋은 말: 빠른 실행 자체를 부정하는 말은 피하고, 빠른 실행을 안전하게 만드는 마지막 확인으로 설명합니다.
</FINAL_ARTIFACT>

<REVIEW_NOTES>
1. 황성빈 대리의 빠른 실행 강점을 먼저 인정해야 합니다.
2. 모든 자료를 같은 수준으로 확인하게 하면 속도가 지나치게 떨어질 수 있습니다.
3. 김원중 과장이 계속 대신 확인하면 후배의 점검 습관이 생기지 않을 수 있습니다.
</REVIEW_NOTES>
```

확인할 것:

- [ ] 자동 분리 확인에서 2주 실행안 `5/5개`가 표시된다.
- [ ] 자동 분리 확인에서 코칭 대화문 `5/5개`가 표시된다.
- [ ] 전체 `10/10개`가 표시된다.
- [ ] FINAL_ARTIFACT가 AI 초안 영역에 표시된다.
- [ ] REVIEW_NOTES가 검토 영역에 표시된다.
- [ ] 검토 입력 항목 중 하나 이상 입력해야 다음으로 이동된다.

## 7. 2주 실행안 화면 확인

확인할 것:

- [ ] 2주 뒤 변화가 자동 입력되어 있다.
- [ ] 이번 주 맡겨볼 일이 자동 입력되어 있다.
- [ ] 김원중 과장 지원 방식이 자동 입력되어 있다.
- [ ] 언제 짧게 같이 볼지가 자동 입력되어 있다.
- [ ] 조심할 표현이 자동 입력되어 있다.
- [ ] 5개 항목을 모두 입력해야 다음으로 이동된다.

## 8. 최종 5줄 대화문 확인

확인할 것:

- [ ] 다섯 개 코칭 문장 입력칸이 각각 보인다.
- [ ] AI 답변에서 분리된 문장이 각 칸에 들어가 있다.
- [ ] 필수 코칭 문장이 비어 있으면 다음으로 이동이 제한된다.
- [ ] 문장을 수정한 뒤 결과 화면으로 이동한다.

## 9. 저장 확인

확인할 것:

- [ ] 결과 화면에 5개 실행계획 항목이 모두 표시된다.
- [ ] 결과 화면에 코칭 대화문 5줄이 표시된다.
- [ ] 저장 전에는 라운드 Map으로 돌아가기 버튼이 비활성화된다.
- [ ] 저장 버튼을 누르면 저장 중 메시지가 표시된다.
- [ ] 저장 성공 후 저장 완료 상태가 표시된다.
- [ ] 저장 성공 후 라운드 Map으로 돌아가기 버튼이 활성화된다.
- [ ] 라운드 Map으로 돌아가면 완료 뱃지가 표시된다.

## 11. 강사용 대시보드 확인

강사용 PC에서 `/?view=instructor`에 접속한 뒤 `데이터 새로고침`을 누른다.

확인할 것:

- [ ] 참여자 수, 전체 응답 수, 완료 응답 수, 참여 팀 수가 표시된다.
- [ ] 세션별 응답 현황과 팀별 진행 현황이 표시된다.
- [ ] 첫 선택 분포가 표시된다.
- [ ] 다시 잡은 판단 분포가 표시된다.
- [ ] 강사용 토의 질문 카드가 표시된다.
- [ ] 라운드별 응답 분포에 R2 응답이 반영된다.
- [ ] 최근 저장 응답에서 테스트1팀 / 김테스트가 보인다.
- [ ] 상세 펼침에서 선택 흐름이 보인다.
- [ ] 상세 펼침에서 AI 답변 검토 3개 항목이 보인다.
- [ ] 상세 펼침에서 5개 실행계획 항목이 모두 보인다.
- [ ] 상세 펼침에서 코칭 대화문 5줄이 보인다.
- [ ] 상세 펼침 하단에 토의 힌트가 보인다.

## 12. 실패 시 빠른 판단 기준

| 증상 | 우선 확인 |
|---|---|
| 저장 URL 미설정 메시지 | Vercel 환경변수 `VITE_GOOGLE_SCRIPT_WEBAPP_URL` |
| 저장 완료가 뜨지만 시트에 없음 | Apps Script 배포 URL, 권한, 시트 ID |
| 대시보드에 데이터 없음 | Apps Script `getDashboardDataV2` 응답 |
| 시트/헤더 점검 실패 | Apps Script 최신 Code.gs 반영 여부, 바운드 스크립트 여부 |
| 자동분리가 일부만 됨 | AI 답변의 항목명과 블록 태그 |
| 다음 버튼이 안 눌림 | 현재 단계의 필수 입력칸 누락 |
| 이전 데이터가 계속 뜸 | 브라우저 localStorage 초기화 또는 입장 화면에서 초기화 |

## 13. 파일럿 통과 기준

- [ ] 사전 점검 화면에서 환경변수, 시트/헤더, 데이터 조회가 모두 정상이다.
- [ ] 교육생 1명이 R2 전체 흐름을 10~15분 안에 완료한다.
- [ ] AI 답변 붙여넣기 후 10개 항목이 자동 분리된다.
- [ ] 저장 결과가 Google Sheets에 반영된다.
- [ ] 강사용 대시보드에서 저장 결과를 1분 안에 확인할 수 있다.
- [ ] 강사가 대시보드 상세 내용을 보고 토의 질문을 던질 수 있다.
