# Bridge AI Leadership Journey v2.0 파일럿 QA 체크리스트

이 문서는 한국공항공사 Bridge AI Leadership Journey v2.0을 교육장 파일럿에서 점검하기 위한 운영 체크리스트입니다.

## 1. 배포 전 필수 확인

### GitHub / Vercel

- [ ] `main` 브랜치에 최신 PR이 병합되어 있다.
- [ ] Vercel 프로젝트가 최신 commit으로 재배포되었다.
- [ ] Vercel Environment Variables에 `VITE_GOOGLE_SCRIPT_WEBAPP_URL`이 등록되어 있다.
- [ ] 환경변수 등록 후 재배포를 다시 했다.

### Google Sheets / Apps Script

- [ ] Google Sheets 파일이 준비되어 있다.
- [ ] `Participants`, `Responses` 시트가 있거나 Apps Script가 자동 생성할 수 있다.
- [ ] Apps Script에 `apps-script/Code.gs` 최신 코드가 붙여넣어져 있다.
- [ ] Apps Script Web App이 새 배포로 발행되었다.
- [ ] Web App URL이 `/exec`로 끝난다.
- [ ] Web App 접근 권한이 외부 웹앱 호출 가능 상태다.

## 2. 교육생 스마트폰 화면 QA

접속 경로: `/`

### 입장 화면

- [ ] 스마트폰 폭에서 화면이 좌우로 밀리지 않는다.
- [ ] 팀명 입력이 가능하다.
- [ ] 닉네임 입력이 가능하다.
- [ ] 팀명/닉네임이 비어 있으면 다음 버튼이 비활성화된다.
- [ ] 라운드 카드를 누르면 선택 표시가 보인다.

### 단계 진행

- [ ] 상황 읽기 화면이 카드 형태로 잘 보인다.
- [ ] 후배 행동 읽기 입력 전에는 다음 버튼이 비활성화된다.
- [ ] 1차 선택 A/B 카드가 스마트폰에서 누르기 쉽다.
- [ ] 선택 이유 입력 전에는 다음 버튼이 비활성화된다.
- [ ] 선택 결과가 사용자의 A/B 선택에 맞게 표시된다.
- [ ] 딜레마 분석 입력 전에는 다음 버튼이 비활성화된다.
- [ ] 다시 판단 선택 후 다음 단계로 이동된다.
- [ ] 육성 방향 선택 후 AI 프롬프트 화면으로 이동된다.

### AI 프롬프트

- [ ] AI 프롬프트가 자동 생성된다.
- [ ] 프롬프트 내용을 수정할 수 있다.
- [ ] `프롬프트 복사하기` 버튼이 작동한다.
- [ ] 복사 성공 메시지가 표시된다.
- [ ] GPT/Gemini/Claude 등에 붙여넣을 수 있다.

### 2주 미니 육성 플랜

- [ ] 성장 목표 입력이 가능하다.
- [ ] 작은 과제 입력이 가능하다.
- [ ] 과장의 지원 입력이 가능하다.
- [ ] 점검 시점 입력이 가능하다.
- [ ] 주의할 점 입력이 가능하다.
- [ ] 모든 항목 입력 전에는 다음 버튼이 비활성화된다.

### 5줄 현장 실행문

- [ ] 5개 문장을 각각 입력할 수 있다.
- [ ] 5개 문장을 모두 입력해야 결과 화면으로 이동된다.

### 임시 저장

- [ ] 입력 중 상단에 `임시 저장됨` 표시가 나온다.
- [ ] 새로고침 후 이전 단계와 입력값이 유지된다.
- [ ] 결과 화면에서 `새 라운드로 다시 시작` 버튼이 작동한다.

## 3. Google Sheets 저장 QA

- [ ] 결과 화면에서 `결과 저장하기` 버튼이 보인다.
- [ ] 버튼 클릭 시 저장 중 메시지가 보인다.
- [ ] 저장 요청 성공 메시지가 보인다.
- [ ] `Participants` 시트에 참여자 행이 추가된다.
- [ ] `Responses` 시트에 응답 행이 추가된다.
- [ ] `round_id`, `team_name`, `nickname`, `growth_goal`, `final_line_1~5` 값이 정상 저장된다.

## 4. 강사용 대시보드 QA

접속 경로: `/?view=instructor`

- [ ] PC 화면에서 대시보드가 열린다.
- [ ] `데이터 새로고침` 버튼이 보인다.
- [ ] 새로고침 시 Google Sheets 데이터를 불러온다.
- [ ] 참여자 수가 표시된다.
- [ ] 전체 응답 수가 표시된다.
- [ ] 완료 응답 수가 표시된다.
- [ ] 참여 팀 수가 표시된다.
- [ ] 팀별 진행 현황이 표시된다.
- [ ] 라운드별 응답 분포가 표시된다.
- [ ] 최근 저장 응답이 표시된다.
- [ ] 응답을 펼치면 2주 미니 육성 플랜과 5줄 실행문이 보인다.

## 5. 파일럿 운영 중 확인

- [ ] 교육생 1명이 먼저 테스트 저장한다.
- [ ] 강사용 대시보드에서 해당 저장값이 보이는지 확인한다.
- [ ] 전체 교육생에게 URL을 공유한다.
- [ ] 저장이 안 되는 교육생이 있으면 새로고침 전 localStorage 유지 여부를 확인한다.
- [ ] 교육 종료 전 모든 팀이 결과 저장을 눌렀는지 확인한다.

## 6. 흔한 문제와 조치

### 저장 버튼을 눌러도 시트에 안 들어오는 경우

1. Vercel 환경변수명이 정확한지 확인한다.
2. 환경변수 등록 후 재배포했는지 확인한다.
3. Apps Script Web App URL이 최신 `/exec` URL인지 확인한다.
4. Apps Script 배포 권한이 외부 호출 가능 상태인지 확인한다.
5. Apps Script 실행 기록에서 오류를 확인한다.

### 대시보드가 데이터를 못 불러오는 경우

1. `/?view=instructor`로 접속했는지 확인한다.
2. Apps Script의 `getDashboardDataV2` action이 포함되어 있는지 확인한다.
3. 브라우저 새로고침 후 다시 `데이터 새로고침`을 누른다.

### 교육생 입력값이 사라졌다고 하는 경우

1. 같은 기기와 같은 브라우저로 접속했는지 확인한다.
2. 시크릿 모드인지 확인한다.
3. `새 라운드로 다시 시작`을 누른 적이 있는지 확인한다.
