# 콘텐츠 줄바꿈 적용 기준

이 문서는 Bridge AI Leadership Journey v2.0의 라운드 콘텐츠 줄바꿈 기준을 정리한 문서입니다.

## 1. 적용 목적

교육생은 주로 스마트폰 또는 태블릿으로 앱을 사용합니다. 따라서 긴 상황문이 한 덩어리로 보이면 몰입도가 떨어지고, 교육장에서 읽는 시간이 길어집니다.

줄바꿈 기준의 목적은 다음과 같습니다.

- 모바일 화면에서 장면을 빠르게 읽게 한다.
- 후배 행동, 리더 판단, 추가 상황, 남은 부담이 구분되어 보이게 한다.
- 라운드마다 텍스트 밀도와 읽기 리듬을 비슷하게 유지한다.
- 사람이 직접 다듬은 수동 줄바꿈은 보존한다.
- 의미상 붙어 읽어야 하는 표현은 줄 중간에서 끊지 않는다.

## 2. 현재 적용 방식

줄바꿈은 두 방식으로 적용됩니다.

| 구분 | 적용 방식 |
|---|---|
| R1 | `r1LineBreakOverrides.ts`와 선택 반응 override에 수동 줄바꿈 적용 |
| R2 | `r2LineBreakOverrides.ts`와 선택 반응 override에 수동 줄바꿈 적용 |
| R3 | `r3RecoveryOverrides.ts`에 수동 줄바꿈 및 재진입 역할 문장 보정 적용 |
| R4 | `r4AiValidationOverrides.ts`에 수동 줄바꿈 및 AI 검증 문장 보정 적용 |
| R5 | `r3ToBossLineBreakOverrides.ts`와 선택 반응 override에 수동 줄바꿈 적용 |
| BOSS | `r3ToBossLineBreakOverrides.ts`, `bossDensityOverrides.ts`에 수동 줄바꿈 적용 |
| 공통 후처리 | `storyLineBreaks.ts`의 공통 자동 줄바꿈 정규화 적용 |

공통 함수는 라운드 override 파이프라인 마지막에 적용됩니다.

```text
기본 라운드
→ override layers
→ 수동 줄바꿈 보정 레이어
→ 이름/직급/표현 정리
→ 방향 제목 정리
→ 전체 라운드 줄바꿈 정규화
```

단, 이미 `\n`이 들어간 문장은 자동 줄바꿈이 다시 적용되지 않습니다.

## 3. 핵심 원칙

### 3.1 수동 줄바꿈 보존

이미 `\n`이 들어간 문장은 자동 줄바꿈을 다시 적용하지 않습니다.

즉, 사람이 직접 리듬을 맞춘 문장은 그대로 유지합니다.

### 3.2 긴 문장만 자동 정리

짧은 문장은 그대로 둡니다.

현재 기준은 다음과 같습니다.

```text
72자 미만: 그대로 유지
72자 이상: 자동 줄바꿈 후보
```

### 3.3 문장 단위 분리

자동 줄바꿈은 문장 단위로 처리합니다.

```text
문장 1
문장 2

문장 3
문장 4
```

기본적으로 두 문장을 한 문단으로 묶고, 문단 사이에는 빈 줄을 넣습니다.

### 3.4 붙어 읽어야 하는 표현은 끊지 않기

아래와 같은 표현은 앞 단어와 뒤 단어가 함께 읽혀야 자연스럽습니다. 줄바꿈을 넣을 때 이 표현의 중간에서 끊지 않습니다.

| 피해야 할 줄바꿈 | 권장 줄바꿈 |
|---|---|
| `숫자 변경`<br>`여부를` | `숫자 변경 여부를` |
| `확정`<br>`여부를` | `확정 여부를` |
| `표현`<br>`수위를` | `표현 수위를` |
| `검증`<br>`기준을` | `검증 기준을` |
| `지원`<br>`범위를` | `지원 범위를` |
| `작은`<br>`역할을` | `작은 역할을` |
| `넘길`<br>`기준을` | `넘길 기준을` |
| `대체 경로`<br>`안내까지` | `대체 경로 안내까지` |

예시는 다음과 같습니다.

```text
좋음:
대신 윤동희 사원은 일정 영향, 외부 공유 여부,
숫자 변경 여부를 하나씩 입 밖으로 꺼냅니다.

나쁨:
대신 윤동희 사원은 일정 영향, 외부 공유 여부, 숫자 변경
여부를 하나씩 입 밖으로 꺼냅니다.
```

```text
좋음:
이 상태에서는 기준을 알아도 다음 문의 앞에서
다시 말문이 막힐 가능성이 큽니다.

나쁨:
이 상태에서는 기준을 알아도
다음 문의 앞에서 다시 말문이 막힐 가능성이 큽니다.
```


## 5. 화면 표시 기준

CSS에서는 아래 요소에 줄바꿈을 보이게 하는 설정이 적용되어 있습니다.

```css
white-space: pre-line;
```

대표 적용 대상은 다음입니다.

- `story-card`
- `step-description`
- `choice-note`
- `text-panel-helper`
- `ai-artifact-card.compact p`

따라서 데이터에 들어간 `\n`은 실제 화면에서 줄바꿈으로 보입니다.

## 6. 향후 콘텐츠 작성 기준

새 라운드를 추가하거나 기존 라운드를 수동 보정할 때는 다음 기준을 따릅니다.

### 상황문

권장 구조:

```text
장면 배경
후배 행동

리더가 본 문제 신호
상사 또는 시간 압박

딜레마가 드러나는 마지막 문장
```

### 선택 결과

권장 구조:

```text
선택 직후 일어난 변화
업무 흐름의 즉시 결과

후배에게 남은 메시지
다음 행동 가능성
```

### 추가 상황

권장 구조:

```text
시간이 지난 뒤 새로 드러난 장면
처음 선택의 비용

리더가 다시 봐야 할 판단 지점
```

### 코칭 대화문

권장 구조:

```text
1. 먼저 풀어줄 말
2. 바로 답하기 전에 물어볼 말
3. 이번 주에 같이 해볼 일
4. 김원중 과장이 봐줄 선
5. 입 밖으로 내면 안 좋은 말
```

특히 3번과 4번은 반드시 구분합니다.

| 항목 | 줄바꿈·표현 기준 |
|---|---|
| 3. 이번 주에 같이 해볼 일 | 후배가 이번 주에 직접 해볼 작은 행동 중심 |
| 4. 김원중 과장이 봐줄 선 | 리더가 어디까지 같이 보고 어디부터 후배가 먼저 해볼지의 경계 중심 |

## 7. 주의할 점

- 줄바꿈을 너무 많이 넣어 한 문장씩 끊어 읽게 만들지 않습니다.
- 교육생이 스마트폰에서 읽을 때 한 화면 안에 핵심 장면이 들어오도록 조정합니다.
- 이미 수동 줄바꿈이 있는 라운드는 자동 함수가 건드리지 않도록 유지합니다.
- 줄바꿈은 의미 단위 구분을 위한 것이지, 디자인 장식이 아닙니다.
- 조사나 의존명사만 다음 줄로 떨어지지 않게 합니다.
- `여부`, `기준`, `역할`, `범위`, `표현 수위`처럼 앞 단어와 붙어야 뜻이 선명한 표현은 한 줄 안에 묶습니다.

## 8. 현재 상태

현재 기준으로는 다음과 같이 적용되어 있습니다.

```text
R1: 수동 줄바꿈 적용
R2: 수동 줄바꿈 적용
R3: 수동 줄바꿈 및 재진입 역할 보정 적용
R4: 수동 줄바꿈 및 AI 검증 현실성 보정 적용
R5: 수동 줄바꿈 및 위임 경계 보정 적용
BOSS: 수동 줄바꿈 및 최종 라운드 완결성 보정 적용
공통: 자동 줄바꿈 후처리 적용
```

따라서 전체 라운드는 모바일 읽기 기준의 줄바꿈 처리가 적용된 상태입니다.
