# v3.4 Theory Terminology Standard

교육생용 화면에서는 학술적 정확성을 유지하되, 번역투나 전문가 내부용 표현보다 국내 교재·논문·언론에서 비교적 익숙하게 접하는 용어를 우선한다.

## 적용 원칙

- 한글 화면 제목은 짧고 익숙한 표준 용어를 우선한다.
- 원개념이 필요한 경우 영문을 두 번째 줄에 병기한다.
- 어려운 용어는 제목에서 제거하고 설명문 안에서 쉬운 말로 풀어쓴다.
- 개념 설명은 `무엇인가 → 이 장면에서 무엇이 보였나 → 리더는 무엇을 하나`의 순서로 작성한다.
- 전문용어 자체를 학습목표로 만들지 않고, 현장 행동을 설명하는 언어로 사용한다.

## A~F 최종 용어

| Case | 화면 한글 명칭 | 영문 원개념 |
|---|---|---|
| A | 자기효능감 | Self-efficacy · Scaffolding |
| B | 행동 중심 피드백 | Behavioral Feedback · Feedforward |
| C | 심리적 안전감 · 귀인이론 | Psychological Safety · Attribution Theory |
| D | 휴먼 인 더 루프(HITL) · 책임성 | Human-in-the-loop · Accountability |
| E | 권한위임 | Delegation · Empowerment |
| F | 역할 명확성 · 팀 상호의존성 | Role Clarity · Team Interdependence |

## 주요 수정

- `비계 설정` → 화면 제목에서 제거. `자기효능감`을 중심 개념으로 제시하고, 설명에서 “필요한 만큼 지원하고 점차 줄이는 방식(Scaffolding)”으로 풀이.
- `행동 피드백 · 피드포워드` → `행동 중심 피드백`. Feedforward는 다음 행동과 미래 개선 방향을 제시하는 접근으로 설명.
- `심리적 안전감 · 귀인` → `심리적 안전감 · 귀인이론`.
- `인간 개입형 의사결정 · 책무성` → `휴먼 인 더 루프(HITL) · 책임성`.
- `임파워먼트 · 위임` → `권한위임`. Empowerment는 영문 원개념과 설명에서 보조.
- `역할 명확성 · 팀 상호의존성`은 표준 개념명을 유지하되 설명을 쉬운 현장언어로 재작성.
